This dataset contains photovoltaic (PV) array polygons mapped in Xinjiang, China, from 2025 satellite imagery.

| Item | Description |
| --- | --- |
| Mapping year | 2025 |
| File | `XJ_PV_2025.gpkg` |
| Format | GeoPackage |
| Layer name | `pv_2025` |
| Geometry | Polygon |
| Coordinate reference system | WGS 84 (EPSG:4326), longitude and latitude in decimal degrees |
| Features | 4,193 connected PV patches |
